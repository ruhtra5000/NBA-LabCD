# NBA - Lab. Ciência de Dados

Projeto Web criado para a matéria Laboratório de Ciência de Dados. O projeto visa fazer análises, gerar gráficos e tabelas sobre uma base de dados de jogos da NBA, focando nos times Cleveland Cavaliers e Brooklyn Nets.

## Como executar o projeto?

### Criação de ambiente virtual

```powershell
# Windows
python -m venv .venv
.venv\Scripts\activate
```

```bash
# Linux / macOS
python -m venv .venv
source .venv/bin/activate
```

### Instalação de bibliotecas

```bash
pip install -r requirements.txt
```

### Rodar aplicação
```bash
python app.py
```
