Informações iniciais

Projeto feito sob uma base de dados contendo estatísticas individuais das equipes da NBA por partida, incluindo resultados, desempenho ofensivo e defensivo e aproveitamento ao longo da temporada. A base completa é composta por 28 colunas e 2238 registros de partida.

As análises aqui apresentadas foram feitas em cima dos dados dos times: Cleveland Cavaliers e Brooklyn Nets.

O campo "GAME_DATE" representa a data em que uma partida ocorreu, esse campo foi tratado transformando-o do formato textual para o formato datetime, permitindo comparações temporais de forma mais simplificada.

Métodos e análise de valores ausentes e inconsistências

Após análise completa da base de dados, pode-se concluir que os dados tem uma ótima qualidade, pois os tipos dos dados estão, de forma geral, corretos, e, além disso, NÃO foram encontrados:

  • Valores ausentes em nenhuma coluna;
  • Registros de partida duplicados;
  • Valores negativos em colunas númericas;
  • Valores inconsistentes em colunas que indicam percentuais;
  • Soma total de rebotes incorreta;
  • Arremessos, cestas de três pontos e lances livres convertidos maiores que os tentados.

MCAR, MAR, MNAR

Se houvessem valores ausentes na base, os mecanismos de análise MCAR, MAR e MNAR poderiam nos dar indícios da razão pela qual eles estão ausentes.

  • MCAR (Missing Completely At Random): Os valores estão ausentes por motivos totalmente independentes das características observadas ou não observadas dos dados. Portanto, a ausência não introduz um viés sistemático na amostra, embora reduza a quantidade de dados disponíveis.
  • MAR (Missing At Random): A probabilidade de um valor estar ausente depende de outras informações observadas no conjunto de dados, mas não depende do próprio valor ausente depois de considerar essas informações. Portanto, é possível utilizar outras variáveis observadas para ajudar a estimar os valores ausentes.
  • MNAR (Missing Not At Random): A probabilidade de um valor estar ausente depende do próprio valor que está faltando, mesmo depois de considerar as demais informações observadas. Portanto, é o mecanismo mais difícil de tratar, pois as informações necessárias para explicar a ausência não estão completamente disponíveis na própria base.

Métodos de investigação de mecanismo de ausência de dados

Teste de Little

Como utilizar

Identifica os diferentes padrões de ausência e compara as características estatísticas dos grupos de observações, utilizando uma estatística qui-quadrado e um p-valor.

Por que utilizar

Permite avaliar se os dados são compatíveis com o mecanismo MCAR, sendo uma das principais ferramentas para investigar a ausência completamente aleatória.

Teste de Jamshidian-Jalal

Como utilizar

Utiliza procedimentos de imputação e testes complementares para avaliar a distribuição dos dados e a homogeneidade das matrizes de covariância entre os padrões de ausência.

Por que utilizar

É uma alternativa ao teste de Little, especialmente útil quando existe suspeita de que os dados não seguem uma distribuição normal multivariada.

Teste de Listing e Schlittgen (LS)

Como utilizar

Compara as características dos participantes que abandonaram um estudo longitudinal com aquelas dos participantes que permaneceram, considerando os diferentes momentos de abandono.

Por que utilizar

Permite investigar se a desistência dos participantes ocorre aleatoriamente, ajudando a identificar possíveis vieses em pesquisas longitudinais.

Regressão Logística de Fairclough

Como utilizar

Cria uma variável indicadora de ausência (1 para ausente e 0 para observado) e utiliza a regressão logística para investigar sua relação com outras variáveis disponíveis.

Por que utilizar

Permite identificar características associadas à probabilidade de ausência, auxiliando na investigação de possíveis mecanismos MAR.
