Informações iniciais

Base de dados contendo estatísticas individuais das equipes da NBA por partida, incluindo resultados, desempenho ofensivo e defensivo e aproveitamento ao longo da temporada. A base completa é composta por 28 colunas e 2238 registros de partida.

O campo "GAME_DATE" representa a data em que uma partida ocorreu, esse campo foi tratado transformando-o do formato textual para o formato datetime, permitindo comparações temporais de forma mais simplificada.

Dicionário de Dados

Este dicionário apresenta a descrição das variáveis utilizadas no conjunto de dados de estatísticas das equipes da NBA por partida.

Tipo do dado Nome antigo Nome novo Significado
Numérica Team_ID id_time Identificador único da equipe.
